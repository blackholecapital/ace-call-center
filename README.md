# ACE Host AI Call Center

ACE Host's custom AI sales and operations dashboard for data-center services, infrastructure products, and AI Automations. Built on:

- Alley AI
- BlackHole Communications Platform
- MessageTrack Dashboard

The ACE dashboard is the frontend default and is also available at `/ace-dashboard/`. It preserves the existing call-center workers, API contracts, and deployment architecture.

Cloudflare production isolation is defined through the `ace` Wrangler environments. See [ACE tenant deployment](docs/cloudflare/ACE-TENANT-DEPLOYMENT.md) for the resource map, provisioning commands, secret inventory, deploy order, and corporate/franchise scaling model.
